# Mort Bay Smart Wireless Socket for Home Assistant

This integration requires a working Mort Bay Smart USB Wireless Controller (i.e., the USB dongle).

Tested on:

+ Mort Bay Smart USB Wireless Controller (Item No. 14113)

Features:

+ **No need to install the supplied control panel software**
+ Control even more than 7 plugs at once
  - Up to 65,536 unique plugs, actually!

Not yet implemented:

+ Direct RF integration with ESPHome devices

Not planned to be implemented:

+ Laptop battery monitoring
  - Can be replaced with other HA integrations like [Glances](https://www.home-assistant.io/integrations/glances/)
